# Online Store SQL Analysis

## 📌 Project Overview

This project analyzes data from a fictional online store using PostgreSQL.

The goal is to practice SQL querying and answer common business questions related to customers, products and orders.

## 🗂️ Database Structure

The database contains three tables:

- customers — customer information
- products — product information
- orders — order information

## 🛠️ Technologies

- PostgreSQL
- SQL

## 📊 SQL Skills Demonstrated

- SELECT
- WHERE
- AND / OR
- IN
- BETWEEN
- LIKE
- ORDER BY
- ASC / DESC
- LIMIT

## 🔍 Business Questions

The analysis answers questions such as:

1. Which customers are from specific countries?
2. Which products are the most expensive?
3. Which products have low stock?
4. Which orders are pending or cancelled?
5. What are the most recent orders?
6. Which orders contain multiple products?
